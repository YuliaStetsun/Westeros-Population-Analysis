Westeros Population Analysis
 Задача: Выполнение тестового задания. Необходимо было сверстать таблицу с данными о населении королевств Вестероса за 2024 и 2025 годы с визуальным выделением динамики (рост/падение/без изменений).
 
Что сделано:
• Создана структура HTML-документа.
• Написаны стили CSS для оформления таблицы.
• Реализовано цветовое кодирование данных (красный — убыль, зеленый — прирост). 
Стек: HTML5, CSS3.
